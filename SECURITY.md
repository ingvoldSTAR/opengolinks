# Security policy

This is a reference project, maintained on a best-effort basis.

If you find a vulnerability, please report it privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for security problems.

There is no guaranteed response time, and only the latest commit on the default branch is considered. Before you run this on the public internet, read the Limitations section of the README.
